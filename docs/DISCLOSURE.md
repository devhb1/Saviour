# Disclosure policy

Blast Radius / Reach reports can map attack surface. Rules:

1. **Opt-in first** for private treasuries — scan only addresses the owner requested, or already-public configs.
2. **Public fixtures** (Term reference, Nov16 incident addresses already in media) may be discussed with redaction of exploit-ready parameter encodings when useful as attack maps for similar live wallets.
3. **UNBOUNDED on a live non-opt-in treasury:** private disclosure first with a fixed window before any public detail beyond tier/fix.
4. Public reports show **tiers and fixes**, not copy-paste exploit parameters.
5. Contact: see README support email.

This policy is required for TheDAO / Grant packaging.
